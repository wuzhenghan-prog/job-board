# AI 助理只读问答与资料库

日期：2026-11-15

## 目标

在现有个人求职管理网站中增加 AI 助理。助理基于岗位、能力档案和资料库回答问题、比较机会并给出建议，同时支持用户主动开启公开网页检索。

AI 是只读顾问。它没有修改岗位、投递阶段、面试记录、能力档案、模型设置或资料库的工具。系统只保存用户主动创建和发送的内容。

## 产品与交互

- 主导航新增 AI 助理页；手机底栏为“概览、岗位库、识别、AI、设置”五项。
- 桌面端采用会话列表和对话主区；手机端使用历史抽屉、固定输入区和安全区避让。
- 岗位详情提供“询问 AI”，创建会话并锁定该岗位；锁定范围可随后扩展。
- 首次打开只展示建议问题，不自动发送或扣额度。
- 回答区分站内事实、通用建议和外部网页来源；无依据时明确标注。
- 会话支持新建、短标题、重命名、删除、停止和重试；最近 10 轮作为上下文，最多保留 50 段。
- 同一次只运行一条回答；停止或断线保留部分内容，并允许创建新版本重试。
- 截图识别和问答共用当前模型，但额度独立：识别默认 30 次/日，问答默认 50 次/日。

## 资料库

- 支持 Markdown、TXT、DOCX、PDF，单份最多 15MB、20 万字符；资料库最多 50 份、200 万字符。
- 原件保存在现有 KV，D1 保存元数据、提取正文和检索分块。
- 文件先由浏览器提取文字，再由服务端校验并原子保存；失败时清理 KV 和 D1 残留。
- 支持文本预览、登录后下载、启用/停用检索和彻底删除。
- 联系方式行不进入检索索引；原文仍仅在登录后可见。
- 删除资料后，旧对话引用显示“来源已删除”，不再返回已删除正文。

## 检索与安全

Worker 固定编排搜索和回答，模型不能调用网站工具：

1. 根据问题中的领域词和短词组检索 FTS5 trigram 索引。
2. 应用岗位锁定、资料范围和启用状态限制。
3. 最多提供 8 个站内片段和必要的能力档案。
4. 联网开启时，最多读取 3 个公开网页，每页不超过约 8,000 字。
5. 模型只能引用本次提供的引用 ID，服务端删除不存在或越权的引用。
6. 网页只保留标题、URL、域名和短摘要，不保存整页全文。

联网只访问公网 HTTP/HTTPS 地址，拒绝本机、私网和云元数据地址，并逐次校验重定向。外部内容视为不可信资料，不得改变系统指令。回答中的原始 HTML 不渲染，外部链接只允许 HTTPS。

## 接口与数据

新增 `/api/assistant` 子路由：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET/POST | `/conversations` | 列出或创建会话 |
| GET/PATCH/DELETE | `/conversations/:id` | 读取、修改范围、删除 |
| POST | `/conversations/:id/messages` | 创建回答并以 SSE 流式返回 |
| POST | `/messages/:id/stop` | 停止并保留部分内容 |
| POST | `/messages/:id/retry` | 取得原问题并创建新尝试 |
| GET | `/usage` | 获取今日问答额度 |
| GET/POST | `/documents` | 列出或上传资料 |
| GET/PATCH/DELETE | `/documents/:id` | 预览、启停或删除 |
| GET | `/documents/:id/file` | 下载原件 |
| GET | `/capabilities` | 返回只读能力声明 |

迁移新增会话、消息、引用、资料、检索分块、FTS5 索引和独立额度表，并为 `ai_settings` 增加问答每日上限。现有岗位数据不迁移或清空。

## 测试与发布

- 覆盖领域规则、资料仓库、FTS5 中文检索、只读路由、SSE、停止、重试、额度、网页安全和页面组件。
- 自动化测试使用假模型与假搜索响应，不调用真实付费接口。
- 运行全部测试、生产构建和 Wrangler 部署预检。
- 发布前增量迁移线上 D1，保留现有岗位、截图、档案及加密模型配置，再更新 Worker 与现有 Pages 入口。
- 公网验收包括登录、站内问答、资料上传与删除、可选联网、SSE 和桌面/390px 手机布局；验收测试数据完成后清理。

## 假设

- 继续使用 Cloudflare 免费套餐、现有 `pages.dev` 地址、KV、D1 和 Queues，不启用 R2。
- 问答沿用已加密保存的 `z-ai/glm-5.3-flash` 配置。
- 不加入语音、图片 OCR、团队协作、自动执行或会话导出。
