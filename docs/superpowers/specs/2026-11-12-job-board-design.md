# 求职机会看板设计记录

产品是单用户、电脑与手机同步的求职机会管理系统，使用私人访问码登录。岗位截图按同一岗位人工归组，后台视觉模型提取公司、岗位、地点、职责、要求、能力画像和基于个人档案的匹配依据。识别结果必须经过可编辑确认页后才进入正式看板。

岗位库支持全文搜索、分类和阶段过滤。投递看板使用待评估、准备投递、已投递、面试中、Offer、已结束六阶段，允许桌面拖拽和手机状态菜单切换。每个岗位支持截止日期、来源链接、备注、多轮面试记录、阶段历史和截图回看。

技术采用 React 与 Vite 前端、Hono Worker API、D1 业务数据、私有 R2 截图和 Queues 异步识别。Cloudflare 只使用免费套餐；视觉模型使用用户自带并充值好的 OpenAI 兼容 API Key。Key 在服务端以 AES-GCM 加密，默认每日最多 30 次识别。个人信息只以能力摘要形式发送给模型。

第一阶段不包含多人协作、自动抓取招聘网站、自动投递、简历生成、邮件或浏览器推送。下一步可在完成真实模型账号与密钥配置后，用三组真实岗位截图验证字段准确率和分类建议质量。
